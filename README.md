## 📚 Subject Details & Coverage

### 1. Advanced Apex Project II (`/apex-project-2`)

* **Focus:** Advanced end-to-end applied AI/ML system architecture, deployment strategies, and capstone project development.
* **Artifacts:** System design documentation, modular codebase, model packaging, and evaluation metrics.

### 2. Big Data Platforms & Analytics (`/big-data-analytics`)

* **Focus:** Distributed computing frameworks (Spark, Hadoop), scalable data engineering pipelines, stream processing, and big data storage architectures.
* **Artifacts:** PySpark scripts, MapReduce tasks, execution logs, and benchmark reports.

### 3. Fundamentals of Finance (`/finance-fundamentals`)

* **Focus:** Financial metrics, asset pricing, risk analysis, portfolio optimization, and quantitative financial modeling for data science.
* **Artifacts:** Valuation models, portfolio optimization notebooks, and financial data analysis reports.

### 4. Machine Learning Model Engineering (`/ml-model-engineering`)

* **Focus:** Productionizing ML models, MLOps, hyperparameter tuning, model monitoring, containerization (Docker), and deployment (REST APIs).
* **Artifacts:** Dockerfiles, CI/CD pipeline configs, inference scripts, and serialized models (`.pkl`, `.onnx`).

### 5. Natural Language Processing & Understanding (`/nlp-understanding`)

* **Focus:** Text pre-processing, word embeddings, sequence models (RNNs/LSTMs), Transformers (BERT, LLMs), and semantic analysis.
* **Artifacts:** Tokenizer configs, model training logs, vector embeddings, and evaluation plots.
